# AI Interview Platform

An AI-powered interview platform that connects candidates with interviewers and provides real-time video interviews, AI-generated questions, and interview feedback.

## Tech Stack

- Next.js
- React.js
- JavaScript
- Tailwind CSS
- Prisma ORM
- PostgreSQL
- Clerk Authentication
- Stream Video
- Gemini AI
- Arcjet

## Features

- AI-powered interview questions
- AI-based interview feedback
- Real-time video interviews
- Interview scheduling and availability
- Candidate and interviewer dashboards
- Clerk authentication
- Credit-based interview system
- Payout management
- PostgreSQL database with Prisma

## Getting Started

Install dependencies:

```bash
npm install
```
